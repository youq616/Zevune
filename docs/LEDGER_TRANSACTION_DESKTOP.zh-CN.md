# 历史交易纳入查询桌面 v1

本模块将原 `ledger_transaction_lookup.lookup` 接入 Windows/Linux Tk 界面，不改钱包、交易、
原生验证器或安装器。目标是查询某个独立交易ID在指定历史账本中是否出现，不执行付款。
始终 NO-FUNDS；原命令行仍可用于自动化，桌面没有后台定时监控和自动重试。

## 启动和操作

需要可信 Python 3.10+ 和 Tk。单独放置源码工具；不可混入旧v2-v9或固定10payload安装目录。

```powershell
python .\scripts\ledger_transaction_desktop.py --no-real-funds
```

填写六项独立输入：停止写入的账本目录、完整256位十六进制ZVARCP01检查点、创世文件SHA256签名域、
交易ID、批准的原生恢复程序、独立程序SHA256。路径必须为绝对路径，其余要求完全沿用原查询器。
选择目录或程序不会自动填写可信摘要，也不会启动它们。不要把从未验证文件中刚计算的摘要当成
独立信任来源。构建文件存在硬链接时，先用原 `native_backend_install.py` 明确安装独立副本；
桌面不自动复制或激活程序，不放宽单链接执行要求。

点击“核对输入”只执行纯格式检查，并在同一窗口完整显示冻结输入。取消按钮是默认焦点；回车不
隐式执行，Escape取消。明确点击“确认仅查询历史交易”才启动一项非daemon工作线程，原查询器
仍须重新执行原生verify-active、完整扫描和末尾复验。禁止同时执行第二项任务，不保存最近路径。

## 状态和复制

找到时显示历史记录高度、从0开始的块内序号、段名与帧偏移。未找到表示该指定历史不含这笔交易，
不能据此授权重复付款。失败与未找到是不同状态，任何异常或不完整回执均清空显示，不显示“未找到”。
不将历史纳入等同于当前结算，不将后续记录数叫作共识确认数；未验证收款人、金额或钱包归属。

桌面先严格检查原查询返回值的精确字段集合、类型、独立pin和位置范围，然后生成不可变显示文本。
这是显示边界检查，不是另一个密码学验证器，不能单独凭一个JSON生成钱包或付款授权。
只有真实查询调用的结果可以进入生产UI；普通测试中的公开显示元数据不充当原生成功替身。

“复制查询交易ID”在一次查询完成后可用，包括查询结果为未找到的情况。复制的是本次查询的标识，
不是付款凭证。只有明确点击复制才改变CLIPBOARD；输入框和文本区禁用自动selection export，
Linux选择文本不会自动接管X11 PRIMARY。屏幕、终端和剪贴板仍可能关联交易，需操作者保护。

修改任何输入立即撤销旧显示和复制许可。任务中程序性改变输入也会让迟到结果失效，不重启任务。
关闭、清除输入及失败都不会擅自清理全局剪贴板历史或改写账本、钱包和交易文件。

## 生命周期和限制

`LookupJob`直接复用原账本桌面的线程准入、启动撤回和实际退出检查。工作线程只调用原查询器及
显示校验，不接触Tk；主线程通过有界队列和绑定任务的一次性计时器票据观察结果。
主窗口复用原编辑修订号、计时器、复制、关闭等方法，但输入、执行目标、显示约束和状态文案独立，
不通过修改共享模块全局变量把旧功能临时改成新功能。既有桌面源码及行为保持不变。

线程启动返回不确定时保持任务归属，禁止重入；ident为空不证明没有操作系统线程。明确完成事件和
实际线程结束都满足才释放任务。完成观察计时器失败时，重复点击关闭只能继续观察原任务，不重新
执行查询。原查询共享的单次300秒预算不变；系统IO及原生清理可能更久，不是硬实时保证。

关闭运行中的窗口会等待原任务结束，不谎称强制取消，不让UI消失后另起后台服务。持续Tk错误或
没有完成信号时可能需要结束应用进程后重开；不保证任意故障下都能优雅退出。完成记录是历史观察，
复制时不再验证账本，也没有持续监控。需可信主机、解释器、目录及原生程序，并停止外部写入。

## 验证边界

工作线程单元测试只使用真实拒绝路径或故意不完整的结果，绝不注入一个成功的密码学验证器。原22项
生命周期场景移植到实际新窗口，包括后台焦点、线程启动中断、计时器中断、重复关闭和X11选择区。
显示层元数据fixture仅验证格式和误导性状态拒绝，与钱包认证或账本重放严格区分。

专用原生驱动保留完整C20安装→原恢复10场景→历史查询流程，另在四类真实恢复历史上操作真实窗口。
首次查询、错误摘要、明确复制、输入失效以及真实结果延迟后的关闭/失效均被验证。安装的单链接副本
来自原安装器；所有正向查询仍使用原Rust，不使用接受型替身。新的双平台工作流保持锁定依赖、
原工具链及20分钟/600秒预算。准确候选的实际CI与非作者复审返回前，不宣称通过或合入main。
