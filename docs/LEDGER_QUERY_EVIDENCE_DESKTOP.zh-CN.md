# 任务／报告变更比较桌面 v1

以图形界面使用 C29 的四种 task/report 内容比较：不创建、导出或执行任务，不运行原生程序，不读取
账本。新入口独立存在，原命令行、报告格式、查询核心及全部已有桌面保持不变。始终 NO-FUNDS。

## 启动和使用

使用可信 Python 3.10+ 和 Tk。在仓库根目录 PowerShell 执行；独立源码包将 scripts 改为 runtime：

```powershell
python .\scripts\ledger_query_evidence_desktop.py --no-real-funds
```

每侧分别明确选择 task（任务文件）或 report（C28 审计报告），填写绝对文件路径和该输入文件的独立
SHA256。类型初始为空，不猜测、不回退；任务内容摘要不能替代报告文件摘要。选择按钮只填路径，
不读取文件、不计算摘要或推断类型。不得从收到的文件自行计算摘要再用它建立信任。

点击“校验并比较”才读取两个输入。默认只展示摘要和统计，不暴露完整 ID、检查点、程序摘要或本机
路径。明确勾选明细后必须重新比较才显示完整公开内容。复制也必须明确点击，仅复制当前显示，
不是付款凭证或审批；选择文本不会自动接管 X11 PRIMARY。剪贴板写入失败不保证恢复原剪贴板内容。

“交换前后”同时交换类型、路径和独立摘要，不自动比较。“清除”重置六个字段及明细选项，不删除文件，
也不擅自清空系统剪贴板。前后只是比较方向，不证明时间先后、链后继或何者更加可信。

## 显示和失效规则

保持 C29 原比较语义：任务和报告可以含相同任务内容，但输入字节不同；报告侧从不声称重新读取了
对应原任务。原任务已经删除时两报告仍可比较，结果必须明确原任务存在性未复查。ID 插入引起的
位置移动不等于保留 ID 的相对重排。没有新的解码器、差异计算规则或外部结果导入入口。

任何字段或明细选择变化，立即清空旧显示和复制许可。在开始、发布结果及复制前再次读取实际变量，
即使变量通知被绕过也不能复用旧路径或意外复制此前详细输出。发布状态的 Tcl 同步通知也可能改变
输入，故最后再做一次修订核对。这里只保护本机可信程序的界面状态，不防御恶意解释器修改对象。

调用原 compare 和 render 后保存不可变的显示对象。检测到输入损坏、变化或读取错误时清空整个结果，
不能显示为“内容相同”“没有变化”或部分成功。错误只显示固定提示，不向控制台暴露底层路径与异常。
恢复复制许可要求完成一次新比较。文件在比较结束后变化不会自动被监控，复制的是已观察的历史显示。

## IO 与关闭边界

本界面同步读取两个有界本地文件，每侧沿用任务8KiB／报告16KiB、32个ID及32KiB输出限制。
没有新线程、计时器或嵌套事件循环；重复调用、交换、清除和关闭在读取期间不会重入。
**磁盘或文件系统阻塞时界面也会等待，不能强制取消，不能据此承诺实时响应或硬截止。** 使用停止外部
写入的可信本机目录，不使用网络共享。Tk 窗口销毁失败时保留再次关闭的入口。

原 compare 的前后字节／文件身份／父目录复核保持。它不是跨文件原子快照、全程锁，也不能防御
恶意文件系统恢复时间戳。普通读取可能更新访问时间；不主动写入内容不是操作系统无元数据副作用。
没有新增完整 ACL、断电安全、签名、最终性、支付许可或校验后监控保证。

## 验证与交付

核心及 GUI 使用真实原 create/export_audit 生成的无价值任务／报告，成功显示直接调用原比较器，
没有注入可接受的模拟原生验证器。覆盖四组合、32项、原任务缺失、错误类型与摘要、明细切换、
绕过变量通知、发布状态通知时输入改变、同字节换文件、只读边界、显式复制与异常／关闭恢复。
原 C28/C29 受限离线 CLI 也重新执行；其审计钩子仅为可信代码测试观测，不是安全沙箱。

新 Windows/Linux 工作流执行真实 Tk 与全部查询任务合同，不构建 Rust，因为本模块不执行后端。
基线成功不能当成本候选验证，作者检查不能替代非作者审查。不要混入旧 v2-v9 或固定10文件安装目录。
整个 P2/P4/P8、旧问题与真实资金禁令不因本模块完成而改变。

Tk 单线程事件语义与测试审计钩子限制依据 Python 官方文档：
