审核按 Rust 状态/钱包/恢复、Go 共识/同步/操作入口、Python 构建/交付三路并行进行。它是工程代码审查，不替代协议、密码学集成或依赖的外部专业审计。当前容器无 Go/Rust 工具链；本地 Python 检查与 Git 对象复现单独计数，原生编译、付款及平台行为必须以当前候选实际 CI 为准。
