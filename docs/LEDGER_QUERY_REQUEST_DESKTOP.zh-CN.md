# 离线查询任务桌面 v1

本模块将 C26 固定任务文件接入 Windows/Linux Tk 桌面：读取独立校验过的任务，展示完整依据和交易
清单，再由用户明确确认执行。它不是任务编辑器、自动调度器或支付界面；不修改原手工输入桌面和
原任务 create/inspect/run，不更改原单遍核心、原生后端、数据格式、锁、容量或固定交付清单。

## 使用

需要可信 Python 3.10+、Tk 和可信源码。实际执行另需独立批准的单链接原生恢复程序与停止写入的账本。

```powershell
python .\scripts\ledger_query_request_desktop.py --no-real-funds
```

独立源码包使用 `runtime` 代替 `scripts`。`--help` 不需要显示器/Tk；没有不带 NO-FUNDS 的启动入口。

填写四项：任务文件绝对路径、独立保存的任务 SHA256、本机停止账本目录、本机批准程序路径。文件
选择按钮只填路径，不读取或执行任务。任务中原有检查点、签名域、程序摘要和有序 ID 仍由固定 JSON
给出，不允许任务文件指定本机路径、命令或自动执行。更换平台/构建仍必须匹配任务绑定的程序摘要。
不能从收到的任务重新计算摘要并赋予信任；摘要不是签名或作者身份认证。

点击“核验任务并核对”后，只读取最多 8 KiB 的任务文件，按独立摘要、固定字段、规范 JSON 及文件身份
校验。确认页显示完整任务摘要、全部1—32个 ID、检查点、程序摘要和本机路径。默认取消，回车不启动
查询；必须明确点击确认。Escape 取消确认而不是取消已运行的原生程序。

## 确认绑定与线程

用户同意的是本次看过的任务快照及本机路径，而不是任意随后出现的相同文件名。工作线程在原 C26
执行入口前后，额外核对审核时保存的字节、文件身份和父目录链。确认后换成相同字节的新文件也会拒绝，
需重新核对；不会把任务文件的摘要相同解释为可以跳过用户看过的版本。

确认前不启动线程或原生程序。确认后采用原非 daemon 任务准入、启动中断持有、完成事件与实际线程
退出双条件，以及一次性计时回调机制。一次只允许一个任务，重复点击不另起查询。没有生产全局替换，
新任务窗口与旧单遍手工窗口可同时存在，各自调用自身入口。复制仅包含本次有序查询 ID，不是付款凭证。

所有四个实际输入在确认、接收结果和复制时再次同步，即使通知被延迟或程序绕开了变量回调，也不能
授权旧路径/旧摘要。输入变化立即撤销结果；真实迟到结果不被显示。结束时不持续监控文件和链状态，
再次核对必须明确重新查询。不能把“复制查询 ID”作为后来文件仍未改变的保证。

核心依然是一次新的原 verify-active、一次完整记录定位及前后账本指纹。原核心300秒预算保持；任务
文件读取和 GUI 等待在其之外，不宣称整个命令300秒硬截止。核验任务阶段在主线程中进行小文件读取，
无嵌套事件循环；文件系统阻塞时仍可能暂时无响应。真正查询在工作线程中，不在工作线程调用 Tk。

## 结果与错误

外层回执必须是原 query_request_run，精确匹配任务摘要、严格的字面布尔标志和字段集合；内层原单遍
结果必须通过全部原格式、类型、检查点、程序摘要、行顺序、计数和位置边界检查。只保存独立不可变的
RequestDisplay；旧窗口的显示对象不能获取新窗口复制许可。显示元数据检查不是密码学验证器。

核验失败、任务中途变化、原生错误或结果不一致使整个结果失效，不能显示成“缺席”或部分成功。错误
不在队列/控制台输出底层异常、任务字节、凭据或程序原始输出。窗口内本机路径与公开查询 ID 仍可能
关联操作者，需保护屏幕、终端、文件与剪贴板历史。

关闭等待真实任务结束，不强杀原生程序，也不冒称已取消。线程启动状态未知或持续计时器/Tk故障会
保留禁止新任务状态；明确再次关闭可继续同一任务收尾，持续失败时需结束本应用。没有任意异步异常
下完全资源回收、密码内存擦除或硬实时退出保证。清除、取消和关闭均不删除任务文件或修改钱包/账本。

## 测试与边界

单元层测试真实任务文件和纯显示元数据，不把合成结果注入 worker 冒充原生成功。真实 Tk 测试覆盖
完整确认、后台不抢焦点、无隐式执行、32 ID、绕过变量通知、审核后同字节替换拒绝、原线程/计时器与
关闭回归，以及新旧窗口互不替换。真正成功路径由独立原生 driver 执行，保留原 C26 安装/恢复/查询
完整链，观察四种真实历史、一次原生调用、32项和显式复制，验证实际成功后的文件身份替换、迟到
结果失效与关闭等待；修改仅发生在测试自己的无价值临时文件中。

新双平台工作流保留原 Rust 工具链/锁定依赖、20分钟作业与600秒原生监督，不削减原验证。独立复审和
准确候选原生结果另按实际记录；工作流存在不等于执行通过。不要将本模块放进旧 v2-v9 或固定10文件
安装目录。需可信主机、解释器、程序和父目录，停止外部写入；无跨文件原子快照、全程锁、恶意文件系统
防护、完整 ACL、断电安全或校验后监控保证。历史纳入不等于当前结算，缺席不授权重试。NO-FUNDS。
