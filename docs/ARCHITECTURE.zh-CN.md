> 2026-09-29 按已合入 C32 源码重建的当前规范；不是找回的历史原稿，不代表协议冻结、完整交付或安全审计通过。基线 merge `ae04190a57bff9ccfbeb056e749f30a9a62c2e02`，tree `7239d12b13b74919e4583cf05b66764994f23a7f`。

## 1. 系统分层

根 Go 模块是原诊断程序和公共连接代码；`integration/cometbft` 是独立 Go 模块，承载 CometBFT 应用、节点操作和参考账本同步；`integration/orchard` 是独立 Rust 模块，承载真实授权、状态执行、持久账本和钱包。根目录 `go test ./...` 不会遍历两个嵌套模块，三者不可混称为一个已测二进制。

当前支付实验调用链：本地 Python 钱包控制台 → 私有 stdin/stdout 钱包请求 → Rust WalletStore 扫描已验证历史、构造证明、保存加密预留及完整签名交易 → 显式导出交易 → 单独的 Go 网络 submit → CometBFT mempool/共识 → poolapp → 本机 Rust worker → 持久账本。收到 mempool 回执不是付款确认。用户目前仍需管理这些分开的步骤，尚非完整在线钱包。

当前收款验证链：明确固定配置 → RPC 区块/签名头 → 固定验证者集和票权签名验证 → 重执行全部交易 → 下一已验证签名头的后置 AppHash 对比 → 参考账本提交 → 钱包重新扫描。同步至已观测 tip-1，不证明全网最新高度或动态验证者网络下的最终性。

来源：`integration/cometbft/labnet/network.go`、`rpc.go`、`sync.go`，`integration/cometbft/poolapp`，`integration/orchard/src/pool.rs`，`scripts/zevune_wallet.py`。

## 2. 信任边界

| 边界 | 当前实现 | 不得推断 |
|---|---|---|
| Python → 原生后端 | 独立程序摘要、固定操作码、有界二进制帧、错误脱敏 | 摘要等于代码签名、可信主机不再必要 |
| 授权 → 账本许可 | 先真实证明/签名，状态规则在预执行、提交和重放重查 | 成功缓存可以再花费、输出 Effects 是权限 |
| 本机节点 → 参考账本 | 固定信任参数、法定票权头与完整重执行 | 只看余额或AppHash即可信任、单一节点知道全球最新状态 |
| 存储 → UI | 独立检查点/回执、完整读取和前后身份复查 | 原子跨文件快照、恶意文件系统防护、持续监控 |
| 证据任务/报告/包 → 接收者 | 严格类型、外部摘要、只创建目标或只读核验 | 签名、付款成功、原件仍在、可以自动执行任务 |

私有 worker/ABCI 不应暴露为公网写入口。已有网络初始化和RPC限定数字回环地址、固定四验证者。四进程测试不能满足四真实机器验收；一个主体持有多把验证者密钥也不等于去中心化。

## 3. 确定性与持久性

`State::apply_transaction`检查域、到期高度、可信锚点、花费标识、输出重复、费用及容量。`PoolStore::prepare` 的结果必须在 `commit` 对当前状态重查，未知提交结果不得自动重试。完整帧字节包括长度及校验开销，不能只统计交易载荷。真实同步写入和锁不可作为优化被删去。

新03活动profile使用1MiB完整记录分段、最多2048段、1000000记录、1GiB逻辑字节；每块16交易、累计承诺65536、钱包256保存记录等其它边界未改变。增量包只节省传递字节，恢复仍重放完整链，不是受信任状态快照导入。旧01/02不自动扩容、迁移或升级。

钱包整理创建新身份和回执，不能撤销别人持有的旧副本；独立检查点仍必要。故障后部分新输出保留，显式核验不证明先前调用成功。参见已有 `ACTIVE_ARCHIVE_V1.zh-CN.md`、`ACTIVE_INCREMENTAL_PACKAGE_V1.zh-CN.md`、`WALLET_DURABILITY.zh-CN.md`。

## 4. 冻结的后续路线

保留现有独立链、成熟 Orchard/CometBFT 和统一代码线；不切换Rollup，不新造证明系统、不加全网查看密钥。停止增加与原八工作包无关的工具界面。依次接通明确远端身份/运维、端到端钱包、隐私传输与查询、验证者状态转换；每次跨信任边界的变更先给规范和非作者设计评审，再做实际调用及反向测试。

初步隐私工程方向选择成熟 Tor v3 onion/SOCKS 传输且不可悄悄回退直连；这是后续实现选择，不是当前运行能力。可信同步规则不能被代理或TLS取代。公开测试分配不变；主网供给、手续费去向和开放质押/退出等决策见 `ROADMAP.md`，不得由本文件暗改账本规则。
