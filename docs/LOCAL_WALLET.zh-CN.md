# M8：本地钱包核心与加密恢复

开发实验，禁止真实资金。这里是库，不是可安装的完整钱包应用。

## 本轮范围

`Wallet` 本地生成随机种子，通过上游 ZIP32 派生 Orchard 密钥。使用测试 coin type 1、账户 0，不将其宣传为 Zevune 主网已登记的派生标准。按索引返回外部收款地址，扫描时同时识别外部收款和内部找零。没有全网查看密钥、云端见证、网络请求、遥测或明文种子导出接口。

`PoolStore::wallet_history` 从已持有独占锁的本地账本读取公开记录，重新验证真实签名、证明、状态转换和最终摘要。钱包对这些有来源约束的记录进行完整重扫，重建资产树、已花费标识和自己能解密的非零票据。同步失败前不替换已有钱包状态。读取历史若发现文件漂移则停用存储实例，不自动修复或截断。

这是本地可信完整节点数据，不是远程 RPC 返回的数据认证，也不是轻客户端或共识最终性证明。已有加密检查点必须出现在新历史的同一条祖先链上；较短历史或具有不同祖先的更长历史均被拒绝。一个没有检查点的新钱包仍需要可信的链起点和同步来源。完整旧备份本身不能证明它是最新版本。

## 付款与待确认状态

钱包在至多八个输入内按金额从大到小选择足够的未花费票据，构造收款及内部找零，生成真实上游证明、签名，并本地验证。多个选中输入共用一次树归约构造各自见证，复用公开证明参数。这个选择策略用于有容量上限的实验，不宣称隐私最优；输入数量和费用元数据仍需要正式隐私评估。

金额和费用使用带溢出检查的整数。金额及费用必须大于零，合计不超过 i64::MAX；到期高度必须大于当前同步高度且不超过后续一百块。这些是当前钱包实验策略，不是完整发行、奖励或全网手续费规则。

同一钱包同时最多一个待确认付款。输入被预留后不能再次使用；加密备份包含预留标识、交易编号和到期高度，恢复后仍保持预留。到期高度是包含端点的：只有已同步高度超过到期高度后才自动释放未花费输入。同步发现相关输入被花费时重新协调余额，不能把输入冲突当作自己的付款成功。

构造交易并不广播，不是到账回执。当前 API 由调用方负责先保存新加密状态、再将交易字节交给广播器；两者尚未做成一个可靠应用级事务。备份不保存待广播完整交易，只保存其 ID 与输入预留。较旧备份可能没有后来的预留，多个进程/设备同时使用同一钱包也还缺少统一所有权和协调机制。这些不能用当前测试成功掩盖。

## 加密备份

`wallet::vault` 使用锁定的 RustCrypto Argon2id 0.5.3 与 XChaCha20-Poly1305 0.10.1。每次加密生成新盐及随机 nonce。Argon2id v19 使用 65536 KiB 内存、3 次迭代、1 lane、32 字节派生密钥。导入文件不能指定任意参数：版本、长度、网络域和固定参数在 KDF 运行前检查，避免畸形备份请求无限资源。

格式 `ZVWLT001`：92 字节认证头、512 字节填充秘密快照、16 字节认证标签，合计固定 620 字节。头部包含格式、实验网络域、固定 KDF 参数、盐和 nonce，整个头部是 AEAD 关联数据。快照保存种子、可选同步检查点和待确认预留，不直接信任文件中声称的余额。恢复后必须通过同步重建余额。

错误口令、被修改的密文/盐/nonce/标签会拒绝解密；无效版本、过大 KDF 参数、重复预留和非规范填充等会拒绝导入。使用公开 Argon2 测试输入和独立 argon2-cffi 参考结果进行互操作检查，但单个向量不是整个备份格式的独立审计。

密码长度 16–1024 字节只是边界，不保证熵或抵抗离线猜测。没有口令恢复后门，失去密码和可用备份可能无法恢复。创建文件仅使用 create_new，不覆盖已有备份；部分写入可能留下无效的新文件，旧备份不被删除。Unix 创建权限 0600；Windows ACL、父目录安全、文件链接竞态及目录持久性需由完整应用继续处理。

自己持有的种子和临时派生密钥/明文缓冲采用 Zeroizing；上游对象副本、操作系统交换区、恶意软件、屏幕和终端记录不在完整擦除保证中。不能将“备份加密”解释成“运行钱包时设备上的秘密永远无法读取”。

## 自动验证范围

真正非零流程使用仅存在于私有单元测试中的初始票据：一次真实资金分配产生两笔收款，钱包合并票据付款、识别内部找零、加密保存待确认状态并恢复、到期后释放，再继续支付；对账时全部收款/找零及费用之和守恒。另测较旧历史、不同祖先链、账本读取后的继续追加、文件漂移、畸形加密备份及共享见证与上游 Frontier 的一致性。

非空创世入口仍为私有测试路径，公开节点没有增发、测试水龙头或外部注资接口。M7 四节点路径仍使用零金额交易；M8 的非零付款在单个本地账本中验证，不能拼接两组结果并称为非零金额四节点收付款已完成。关闭/恢复钱包在测试进程内执行，不等于跨设备实际操作、所有断电场景或跨地域网络测试。
